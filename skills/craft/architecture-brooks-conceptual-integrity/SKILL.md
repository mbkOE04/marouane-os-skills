# Brooks: conceptual integrity
## When to use
Design reviews; deciding who owns architecture; trimming features.
## Principles
- Conceptual integrity is the most important consideration in system design.
- Prefer one coherent design to many good but independent ideas.
- Separate essential complexity from accidental complexity.
- Few minds design; many build.
## Checklist
- Is there one named owner of the architecture?
- Do new features fit the existing model?
## Questions
Does this feel like it was designed by one mind?
