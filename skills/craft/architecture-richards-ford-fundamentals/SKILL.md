# Fundamentals of Software Architecture
## When to use
Choosing an architecture style; recording decisions; weighing trade-offs.
## Principles
- Everything is a trade-off; there are no best practices, only context.
- Identify the few driving architecture characteristics (availability, scalability, security...).
- Record decisions as ADRs with context, decision, consequences.
- Use fitness functions to guard characteristics.
## Checklist
- Top 3 characteristics named and ranked?
- Alternatives and costs written down?
## Questions
What are we giving up by choosing this?
